% Box-drawing 与箭头字符（│ ─ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼ → ↑ 等）的 Unicode East Asian
% Width 属性是 "Ambiguous"（A），xeCJK 默认按 CJK 宽度（=2 ASCII）渲染。这导致作者
% 在等宽编辑器（按 1 ASCII 宽画图）里画的 ASCII art 在 PDF 里宽度被翻倍，各列错位。
% 把它们归类为 Default（西文）就按 1 ASCII 宽渲染，各列对齐。
%
% 注意：
%  (1) 必须用 Default 类，不要用 HalfLeft（HalfLeft 是给"半角左/右标点"用的，
%      仍会注入 CJK 间距胶水，导致字符间额外加宽 ~16%）。
%  (2) **不要把 × 加到 Default 类**：作者在中文 markdown 里画 ASCII art 时，× 通常
%      被当作全宽汉字宽度算（如 `×N` 占 1 个汉字 = 2 ASCII），加到 Default 后会变
%      半宽，反而让该行总宽变短 ~15px，破坏对齐。让 × 走 xeCJK CJK 类（默认全宽）。
%  (3) 归入 Default 后这些字符改用当前西文字体；Palatino 没有箭头和几何符号，
%      所以下面 newunicodechar 把它们显式交给 \textsymbol（Sarasa Fixed SC）。

  `│, `─, `┌, `┐, `└, `┘, `├, `┤, `┬, `┴, `┼,
  `═, `║, `╔, `╗, `╚, `╝, `╠, `╣, `╦, `╩, `╬,
  `╭, `╮, `╯, `╰,
  `→, `←, `↑, `↓, `↔, `↕,
  `▲, `▼, `◀, `▶, `△, `▽, `◁, `▷,
  `●, `○, `■, `□, `◆, `◇, `★, `☆
}
